## Desktop/browser assumptions and risks

- `window`, `document`, localStorage, pointer lock, Canvas2D/WebGL2, mouse wheel, keyboard codes and window viewport sizes.
- `blur` clears only keys, not drag/jump; pagehide/beforeunload write saves without a native lifecycle flush.
- Menu/dialogue state is not an input layer, and UI-focused keyboard events can reach the world.
- Saving to a selected non-loaded slot can replace another journey; load has no unsaved-progress confirmation. Unknown/newer schemas must not be silently overwritten by autosave.
- Mobile browser scrolling, simultaneous pointers, Android Back, safe areas, portrait/landscape and interrupted saves need explicit handling.
